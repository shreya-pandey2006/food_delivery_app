# FLUTTER UI RECREATION TASK

## Food Delivery App
• UI Implementation & Basic Navigation

## 1. Task Objective
Recreate the provided Food Delivery App UI in Flutter as accurately as possible. The task focuses on Flutter widgets, layouts, styling, reusable UI components, and basic navigation.
## 2. Screens to Implement
•	Home Screen: Header, search bar, offer banner, categories, food cards, and bottom navigation.
•	Food Details: Food image, name, rating, price, description, ingredients, options, and Add to Cart UI.
•	Cart: Delivery section, cart items, coupon/offer, bill details, total, and checkout UI.
## 3. Required Navigation
•	Home → Food Card → Food Details
•	Home → Cart Icon → Cart
•	Food Details → Back → Home
Use basic Flutter navigation such as Navigator.push().
## 4. Functionality Not Required
All controls are UI-only unless mentioned in the navigation section. Do not implement:
•	Search, category filtering, Add to Cart, quantity changes, favorites, coupons, or checkout.
•	API/backend, database/Firebase, authentication, or real state management.
## 5. UI Requirements
•	Match the reference images in layout, spacing, colors, typography, icons, cards, and overall appearance.
•	Use appropriate Flutter widgets and reusable components for repeated UI elements.
•	Keep the UI responsive and free from unnecessary overflow.
•	Use static/local data and assets; no API is required.

## Evaluation
Area	Focus
UI Accuracy	Similarity to the provided design.
Flutter Knowledge	Widgets, layouts, styling, and reusable components.
Navigation	Food card and Cart navigation work correctly.
Code Quality	Clean, readable, and organized code.
## 7. Submission
Submit the complete Flutter project. The app should run successfully on an Android device/emulator and include the three recreated screens with the required navigation.
